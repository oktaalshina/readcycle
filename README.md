# READCYCLE – Static Demo

This repository contains a **static demo version** of READCYCLE,
built for UI/UX showcase and front-end logic demonstration.

> ⚠️ This is a **demo-only project**.  
> Backend features such as authentication, posting, and data persistence are **not available**.

---

## 🎯 Purpose

This demo is created to:
- Showcase UI design and layout
- Demonstrate client-side logic (filtering, pagination, rendering)
- Provide a live demo deployable on platforms like Vercel

---

## 🧩 Features (Demo)

- Landing page (Index)
- Login & Register pages (UI only)
- Timeline with:
  - Client-side pagination
  - Client-side search & filters
  - Expandable comments (dummy data)
- Posting page (UI + image preview, no submission)

---

## 🛠 Tech Stack

- HTML5
- CSS3 (Bootstrap 5)
- Vanilla JavaScript

---

## 🚫 Limitations

The following features are **intentionally disabled** in this demo:
- User authentication
- Posting data to server
- Comment submission
- Data persistence

All actions will show:
> "Fitur tidak tersedia pada live demo."
